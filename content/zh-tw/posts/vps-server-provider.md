自從上一篇文章講了[如何保護 VPS 之後](https://blusewill.top/zh-tw/posts/4112316/)

我們可以來聊聊到底要買哪家 VPS 了，你以為會很複雜其實很簡單！

首先你要知道你要多少的資源，我通常的話你髓便給我一個 Linux 伺服器我都可以架設出很多東西

不太會去注重硬體速度的部分（除非我今天開的是 Minecraft 伺服器那另當別論）

## 大公司

那當然第一個想到 VPS 最安全就是這些大公司的伺服器啦！

這些大公司的伺服器通常都會有好用的後端 UI (防火牆，備份等)

或是已經幫你用好全部環境的伺服器環境！

那大公司你有 GCP, AWS, Orcale, Akamai 可以選

那我自己是用 Akamai Cloud 純粹就是因為有朋友在用，加上他的工商太多了

工商多到什麼程度呢？就連我都可以打工商啦！

你現在可以[點擊這個連接](https://www.linode.com/lp/refer/?r=ef32bcb648b281045da1a3a61da944a31a81761c)使用我的促銷網址來購買 Akamai Cloud VPS

前兩個月會有免費的 100 美金額度給你玩喔！

但雖說是這樣沒錯但 Akamai Cloud 的穩定性也是不輸 GCP 或是 AWS 的

而且撇除免費方案，一個月只要 150 塊錢台幣不買嗎？

而且又買的到日本伺服器，讓 IRL 直播不會變卡，是個還不錯的投資！

## 日本大公司

好講完了世界上的大公司，是時候來講日本的大公司了！

畢竟日本的大公司會比國際大公司來的還要便宜很多

尤其是你買越長的時間就會越便宜！

這邊推薦的是日本 GMO 的 [ConoHa](https://www.conoha.jp/) VPS

應該是日本目前最大的 VPS 廠商了，但是這廠商最大的問題就是沒有額度！

沒錯！我買的時候 ConoHa 都是沒有額度的！他都會叫我找其他時間在來看看！

還有會有限速還有資安的風波，所以要稍微小心謹慎地使用

如果想要看更多其他日本 VPS 廠商，可以看這篇巴哈的文章！

https://forum.gamer.com.tw/Co.php?bsn=34421&sn=4361

## 中小公司，民間廠商

通常這些不能可以保證為你帶來穩定度跟資安的問題！

但可以確定的是他真的很便宜！

一年只需要 600 多塊台幣的伺服器不知道你有沒有見過！

這些比較特別的伺服器都可以去 [LowEndBox](https://lowendbox.com/) 看看！

通常這上面都是中型企業提供的優惠或是最便宜的方案！

那如果你要來看民間廠商的話就要去 [LowEndTalk](https://lowendtalk.com/) 論壇！

通常這上面都會是最便宜的方案！只是你犧牲了資安跟網路速度！

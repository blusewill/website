忽然我的 Facebook 跟 Twitter 都被洗版了，因為 Firefox 的吉祥物 Kit

說他是新的吉祥物也對，他是 2025 年 11 月出來的吉祥物

你要說他不是新的的吉祥物也對，畢竟也不是最近公佈的消息

但我一直被洗版的原因是因為 Mozilla 幫 Kit 做了一套獸裝！？

![Kit Mascot](/zh-tw/img/firefox-mascot/Kit-Mascot.webp)

就因為這樣子，忽然 Kit 就把我的 Facebook 跟 Twitter 洗版了

尤其是 GTA VI 剛出阿，裡面可是有 Anti-Furry 協會的！發這個出來更是有話題！

## 我第一次看到 Kit

其實很多人都是在這次 Firefox 的熱線看到 Kit 的樣子的。

但我其實早在去年就知道了，因為那時候國外就有在講 Kit 這個可愛的吉祥物了

{{<youtube dwSeg-2rQT8>}}

但那時候 Firefox 正在一個很尷尬的點

當時 Mozilla 公司內部有一點小問題，當時 2022 ~ 2025 都有大裁員的請況！

然後 Mozilla 又因為在 SUMO 導入機器翻譯而引發日本翻譯社群的不滿，最後讓日本 SUMO 社群直接不幹了。

然後 Mozilla 也在這幾年重新設計他們公司設計！讓有一些人會思考那些省下來的錢是不是都拿去重新設計跟設計了。

這其實是當時 Kit 剛出來的景象，但當時有個更大的問題！就是到底這樣的商業模式有沒有用？

可不可以讓一些在 Chrome 或是 Edge 上面的人換過來使用 Firefox 呢？

那時候 Kit 就是出生在這種請況下！非常不太好的 Timing

## 來聊一下 Kit 的設計

<img src="/zh-tw/img/firefox-mascot/firefox-mascot-sitting-looking-up-rgb.webp" alt="Kit Mascot" width="300"/>

首先 Kit 這隻非常可愛的物種，你不能以狐狸來形容他！

為什麼呢？因為 Firefox 的吉祥物同時也是 Red Panda (小熊貓)！

原因是因為小熊貓別名又稱爲 Firefox

> 這點你可以看這個好幾年前有人問的問題，Firefox 的 Logo 是狐狸還是小熊貓

> https://support.mozilla.org/en-US/questions/988854

> 還有這裡看 Firefox 的名字由來

> https://www-archive.mozilla.org/projects/firefox/firefox-name-faq.html

但你又說他是小熊貓嗎？也不像阿！

那他到底是什麼物種呢？其實是小熊貓跟狐狸的混合體！

所以如果以後有人問你 Kit 是什麼物種的話，你就回他 Firefox 好了！

畢竟這也是他們說明 Kit 的設計的 [Blog](https://blog.mozilla.org/en/firefox/meet-kit/) 講的！

![About Kit Blog](/zh-tw/img/firefox-mascot/librewolf_o6mckLh37u.webp)

然後 Kit 的設計也走了很多很稀奇的點子，像是 Kit 其實是一個表情派的動物！

因為 Kit 其實是沒有嘴巴的！因為當時 Mozilla 想要走表情派

但又不想要讓他變成會講話的卡通人物，所以他的表達方式就會待在他的表情跟移動上呈現

這也就可以解釋為什麼他會有象徵性這麼大又長的尾巴！就是為了要有豐富的表情量！

我是覺得效果有達到啦！不知道你們覺得呢？

## Kit 不是第一個 Firefox 的吉祥物

Kit 其實不是第一隻 Firefox 的吉祥物，因為第一隻吉祥物是沒有被國際版 Firefox 收入的

第一隻 Firefox 的吉祥物只有在日本才會看到！叫做 Foxkeh

<img src="/zh-tw/img/firefox-mascot/200704.webp" alt="FoxKeh" width="300"/>

是從 2006 ~ 2011 年日本那邊的 Firefox 吉祥物！

那這一隻確定就是狐狸的啦，不用擔心說到底是小熊貓還是狐狸！

那當時後就是 Mozilla 日本想要推廣 Firefox 在日本的市佔率！所以才做出了這個吉祥物！

雖說沒有在更新了，但是你到現在都還可以上他的網站！ https://foxkeh.jp/

![FoxKeh Website](/zh-tw/img/firefox-mascot/IGLV8CLdQB.webp)

那當然有人在 Mozilla 十週年也做出了 FoxKeh 跳倉鼠舞的網站！有興趣的話可以去看一下！

https://foxkehdance.com/

> 20 週年版本 : https://foxkehdance.com/2.0/

## 那到底 Kit 是失敗，還是成功呢？

就目前來看，很難說！

畢竟雖說 Kit 在 3 月正式發布在 Firefox 頻道之後有微微的增加市占率

![StatCounter](/zh-tw/img/firefox-mascot/StatCounter-browser-ww-monthly-202510-202610.webp)

但是有打敗 Edge 的地位嗎？並沒有！更不要說 Chrome 了

但他會有機率打敗 Edge 上位嗎？這個就只能在看看了！

畢竟這應該又會是一場 Microsoft 跟 Mozilla 之間的瀏覽器大戰了！

又回到了 Netscape 跟 Internet Explorer 對決的年代了呢！

那這邊是小品！我們就下次再見啦！
